# Pic Chop Crop — desktop (Tauri)

Собрано в Linux-песочнице без возможности живого запуска — синтаксис и логику
проверял статически (`rustc`-парсер, `node --check`, сверка id/тегов). Реальную
сборку, отладку и багфиксы (dialog-плагин, drag&drop, вложенная папка при
распаковке) прошли уже вместе, по ходу дела.

## Возможности

- Открывается как обычное окно, не браузерная вкладка
- Точная обрезка под заданное разрешение (крап всегда экспортируется ровно
  W×H, без искажения — растягивается/сжимается, а не обрезается криво)
- **Открытие сразу в режиме фокуса** — файл показывается на всё окно, без
  рамки и настроек: сначала просто смотришь картинку. **Esc** (или **F**)
  возвращает рамку и настройки; строка сверху проявляется при наведении мыши
- **Холст на всё окно** — сверху тонкая строка: имя файла, размер исходника,
  масштаб (клик — вписать ↔ 100 %), ‹ n / N › по папке; снизу плавающая
  панель: соотношение, ширина × высота, формат, «Сохранить»
- **Рамка как чертёж** — по краям рамки размерные линии: сколько пикселей
  исходника в неё попадает и во сколько раз их пересчитают (`↓ 0.78×`,
  `1:1`, жёлтое `↑ 1.5×` — картинка растянется и может потерять чёткость)
- **Соотношения** — 12 вариантов (1:1, 4:3, 16:9, 21:9, 9:16, 4:5 …).
  Сохраняется длинная сторона: из 1920×1080 вариант 9:16 даёт 1080×1920,
  1:1 — 1920×1920. Размер не из списка показывается дробью (3840×1080 → 32:9)
- **Готовые размеры** — 1920×1080, 2560×1440, 3840×2160, 1080×1080,
  2560×2560, 3840×3840, 1080×1920, 1200×630
- Кнопка ⇄ (или **X**) меняет местами ширину и высоту
- **Зум колесом мыши** с центром под курсором; **Pan** — тянуть картинку за
  пределами рамки (средней кнопкой — всегда)
- **Точный сдвиг рамки** — Shift + стрелки на 1 px исходника, Ctrl + Shift —
  на 10 px
- Файл можно бросить в окно в любой момент, в том числе поверх открытого
- «Сохранить» (Ctrl+S) — нативный диалог "Сохранить как" (с фоллбэком на
  браузерное скачивание, если диалог недоступен). В файл уходит ровно то, что
  в рамке, поэтому если рамка скрыта, первое нажатие сначала показывает её
- Если приложение открыто через "Открыть с помощью" на файле — доступно
  пролистывание остальных jpg/jpeg/png в той же папке (‹ › или стрелками
  ←/→), в том же порядке, что в Проводнике
- Интерфейс подстраивается под размер окна и масштаб Windows (проверено от
  окна 720×480 до 4K); минимальный размер окна — 720×480
- Ничего не отправляется в сеть и не пишется в AppData/реестр помимо того,
  что ставит сам инсталлятор (см. деинсталляцию ниже)

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Esc` / `F` | выйти из режима фокуса / войти в него |
| `C` (или русская `С`) | показать/скрыть рамку |
| `←` / `→` | предыдущий / следующий файл в папке |
| `Shift` + стрелки | сдвинуть рамку на 1 px (с `Ctrl` — на 10 px) |
| `X` | поменять ширину и высоту |
| `0` / `1` | вписать в окно / масштаб 100 % |
| `Ctrl+S` / `Ctrl+O` | сохранить / открыть файл |
| `?` | список клавиш |

## Пререквизиты (одноразово)

1. Rust 1.77+ через rustup: https://www.rust-lang.org/tools/install
   (`rustc --version` должен быть ≥ 1.77 — версия из старых источников типа
   стандартного apt/choco может быть слишком старой)
2. "Desktop development with C++" в Visual Studio Build Tools —
   без этого линковка на Windows не пройдёт:
   https://v2.tauri.app/start/prerequisites/#windows
3. Node.js — у тебя уже есть

## Сборка

```powershell
cd pic-chop-crop
npm install
npm run tauri dev      # живой запуск для проверки, перед сборкой инсталлятора
```

Prev/Next и открытие "с диска" в dev-режиме не проверить — они появляются
только когда .exe запущен с путём к файлу в аргументах (см. ниже).

```powershell
npm run tauri build
```

Инсталлятор появится в
`src-tauri\target\release\bundle\nsis\Pic Chop Crop_0.1.0_x64-setup.exe`.
Запусти его — он ставит файловые ассоциации для jpg/jpeg/png сам, но Windows
может всё равно попросить подтвердить вручную (тот же флоу "Открыть с
помощью", что мы уже проходили).

## Полное удаление

Приложение ничего не пишет в AppData, кэш или реестр помимо того, что делает
сам инсталлятор при установке — деинсталляция должна быть полностью чистой.

> Раньше приложение называлось **Exact Crop**. Новая версия ставится как
> отдельная программа и старую не заменяет — удали "Exact Crop" теми же
> шагами (пути — `…\Exact Crop\uninstall.exe`).

1. **Через Windows** — Параметры → Приложения → Установленные приложения →
   найди "Pic Chop Crop" → Удалить. Это штатный NSIS-деинсталлятор: он сносит
   сам .exe, ярлыки в меню "Пуск" и файловые ассоциации для jpg/jpeg/png.
2. **Если не находится в списке** — деинсталлятор лежит рядом с самой
   программой, обычно
   `%LOCALAPPDATA%\Pic Chop Crop\uninstall.exe` (для установки "только для
   меня") или `C:\Program Files\Pic Chop Crop\uninstall.exe` (если ставил для
   всех пользователей). Запусти его напрямую.
3. **Проверить файловые ассоциации** — иногда Windows после удаления
   программы забывает автоматически переключить jpg/png обратно на
   "Фотографии". Параметры → Приложения → Приложения по умолчанию → найди
   `.jpg`/`.jpeg`/`.png` → смени, если всё ещё указывает на Pic Chop Crop.
4. **Убрать исходники и папку сборки** (не обязательно, но если хочешь
   подчистить диск целиком) — на диске остаются только:
   - сама папка проекта `pic-chop-crop\` (исходники, можно удалить
     целиком — `rd /s /q pic-chop-crop` или просто снести в Проводнике)
   - `src-tauri\target\` внутри неё — это кэш сборки Rust, может весить
     несколько гигабайт; безопасно удалить, при следующей сборке
     пересоздастся заново

## Если что-то не работает

- **Окно открывается, но пусто / кнопки не реагируют** — открой DevTools
  (правый клик → Inspect в dev-сборке) и посмотри консоль. Скорее всего не
  хватает прав в `src-tauri/capabilities/default.json` (`core:default` +
  `dialog:default` — по документации Tauri v2 этого достаточно, но это
  единственное место, которое я не смог проверить вживую до запуска).
- **Рамки и настроек не видно** — так и задумано: файл открывается в режиме
  фокуса. Нажми **Esc** (или **C**, **F**), либо наведи мышь на верх окна.
- **Drag&drop не работает** — проверь, что в `tauri.conf.json` у окна стоит
  `"dragDropEnabled": false` (без этого Tauri перехватывает файлы на
  нативном уровне и веб-событие `drop` до страницы не долетает).
- **Иконка — просто угловые скобки** — это плейсхолдер. Замени командой:
  `npx tauri icon путь\к\любой\квадратной\картинке.png`
- **Prev/Next не появляются** — они завязаны на то, что .exe запущен с путём
  к файлу в аргументах (так Windows передаёт файл при "Открыть с помощью"). Из
  ярлыка/меню Пуск без файла — только drag&drop, это ожидаемо.
- **Инсталлятор исчезает после сборки на Windows 10** — почти наверняка
  правило ASR "Block executable files from running unless they meet a
  prevalence, age, or trusted list criterion"
  (`01443614-cd74-433a-b99e-2ecdc07bfc25`) или Controlled Folder Access.
  Проверить: `Get-MpPreference` и журнал событий (ID 1121–1124).

```
pic-chop-crop/
├── package.json           # только @tauri-apps/cli, фронтенд без сборщика
├── frontend/index.html     # весь UI: крап, зум/пан, фокус-режим, пилюля настроек
└── src-tauri/
    ├── Cargo.toml
    ├── tauri.conf.json     # окно, dragDropEnabled, файловые ассоциации, иконки
    ├── capabilities/default.json
    ├── icons/
    └── src/main.rs         # 4 команды: get_initial_file, read_file_bytes,
                             # list_siblings, write_file_bytes
```
